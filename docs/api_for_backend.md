# 추천 서버 API — 백엔드 연동 안내

작성: 2026-08-14 · 대상: 백엔드 담당자
현재 단계: **통신 확인**. 추천 기능은 아직 붙이지 않았고, 먼저 요청이 오가는지만 봅니다.

---

## 1. 지금 쓸 수 있는 것

### `GET /api/v1/ping`

숫자 하나를 돌려줍니다. 추천 모델과 무관하게 동작하므로, 응답이 오면 **네트워크·포트·
프록시 경로가 정상**이라는 뜻입니다.

```
GET http://<주소>:8000/api/v1/ping?n=42
```

```json
{
  "value": 42,
  "received": 42,
  "server_time": "2026-08-14T09:15:05.267947+00:00",
  "model_loaded": false
}
```

| 필드 | 뜻 |
|---|---|
| `value` | 서버가 돌려주는 숫자. `n`을 보내면 그 값, 생략하면 `0` |
| `received` | 요청에 실려 온 `n`. 값이 그대로 오면 **요청 본문이 전달됐다는 증거** |
| `server_time` | 서버 시각(UTC, ISO8601). 시계·타임존 확인용 |
| `model_loaded` | 모델 적재 여부. **이 단계에서는 `false`가 정상** |

- `n`은 선택입니다. 정수가 아니면 `422`가 돌아옵니다(타입 검증 동작 확인용).
- 인증 없음. 지금은 사설망(Tailscale) 안에서만 접근하는 전제입니다.

### `GET /api/v1/health`

서버가 살아 있는지와 모델·인덱스 준비 상태를 봅니다. 헬스체크·모니터링용입니다.

```json
{ "status": "healthy", "model_loaded": false,
  "index_built": {"movie": false, "music": false, "book": false} }
```

### `GET /docs`

브라우저로 열면 **모든 엔드포인트를 눌러서 시험해볼 수 있는 화면**이 나옵니다
(FastAPI가 자동 생성). 연동 중 확인할 때 유용합니다.

---

## 2. 나중에 붙을 것 (아직 동작하지 않음)

인터페이스만 미리 공유합니다. 모델·인덱스를 올리면 활성화됩니다.

### `POST /api/v1/recommend`

```json
// 요청
{ "query": "비 오는 날 듣기 좋은", "domain": "music", "top_k": 10 }

// 응답
{ "query": "...", "domain": "music",
  "results": [ { "item_id": "...", "domain": "music", "score": 0.72,
                 "title": "...", "extra": {...} } ] }
```

- `domain`: `movie` | `music` | `book`. 생략하면 세 도메인 통합 검색
- `top_k`: 1~100, 기본 10
- 모델이 아직 안 올라간 상태에서는 **503**을 돌려줍니다 (`/ping`은 200)

### `GET /api/v1/item/{domain}/{item_id}`

아이템 메타데이터 조회. 없으면 404.

---

## 3. 접속 주소

화요일에 정합니다. 현재 후보는 **Tailscale**입니다 — 양쪽 컴퓨터를 같은 사설망으로
묶어주는 도구로, 포트포워딩이나 공인 IP 노출 없이 `100.x.y.z` 형태의 고정 주소로
서로 접근할 수 있습니다. 인터넷에는 아무것도 열리지 않습니다.

정해지면 아래 형태의 주소를 드립니다.

```
http://100.x.y.z:8000/api/v1/ping?n=42
```

---

## 4. 미리 정해두면 좋은 것

화요일에 논의할 항목입니다. 미리 의견을 주시면 그에 맞춰 준비하겠습니다.

1. **포트** — 지금은 8000. 백엔드 쪽 규약이 있으면 맞추겠습니다.
2. **경로 규칙** — 지금은 `/api/v1/...`. 프리픽스를 바꿔야 하면 알려주세요.
3. **인증** — 사설망 안이라 없어도 된다고 보는데, 정책상 필요하면 헤더 방식으로 넣겠습니다.
4. **타임아웃** — 추천 1건은 수십 ms 예상이지만, 서버 기동 직후 첫 요청은 모델 적재로
   느릴 수 있습니다. 백엔드 쪽 타임아웃 값을 알려주시면 그에 맞춰 준비 상태를 다루겠습니다.
5. **에러 형식** — 현재 FastAPI 기본(`{"detail": "..."}`). 공통 규격이 있으면 맞추겠습니다.

## 5. 참고 — 서버 실행 방법 (추천팀용)

```bash
./scripts/serve.sh              # 기본 8000 포트
PORT=9000 ./scripts/serve.sh    # 포트 변경
```

실행하면 접속 가능한 주소(LAN / Tailscale)를 함께 출력합니다.
