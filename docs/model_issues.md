## 2. 서비스에는 해당 없음

### 2-1. 질문 하나에 한 도메인이 결과를 독차지한다 — 평가 스크립트에서만 나타남

영어 질문 40개 중 12개에서 상위 10개가 전부 한 도메인이다(qlora_off). 이것은 세 도메인을
한 줄로 섞어 순위를 매기는 **우리 평가 스크립트의 통합 검색**에서 잰 값이다.

**서비스에서는 일어나지 않는다(10/25 백엔드 코드 확인).** 백엔드의 아이템 검색은 보드
추천(`RecommendationService`)과 텍스트 검색(`SearchService`) 모두 `searchEachValue`를 거쳐
콘텐츠 종류별로 따로 검색하고 정해진 개수를 가져온다(보드 하나에 책 4 / 영화 2 / 음악 2).
섞어서 순위를 매기는 검색이 없으므로 독차지가 생길 자리가 없다.

**도메인 뭉침도 도메인 안의 순위는 바꾸지 않는다.** 아이템 벡터를 "도메인 공통 성분 +
아이템 고유 성분"으로 나누면, 점수 = 질문·공통 성분 + 질문·고유 성분이고, 첫째 항은 같은
도메인 안에서 모든 아이템에 같은 값이다. 도메인별로 따로 검색하는 한 뭉침의 정도와 무관하게
순위는 그대로다. 사용자 취향 벡터가 많이 담긴 도메인 쪽으로 끌려가는 효과도 같은 이유로
도메인 안 순위에는 영향이 없다.

아래는 원인 진단과 지난 시도의 기록이다.

- **원인:** 아이템 벡터가 도메인별로 뭉쳐 있다. 학습된 768차원 벡터에 선형 분류기를 걸면
  도메인을 98.7% 맞히고, 필드 이름을 지운 설명문만으로도 텍스트 분류기가 99.5% 맞힌다.
  도메인 지문은 필드 이름이 아니라 어휘·문체다.
- **학습으로 고치려던 시도는 실패했다.** 4-2 도메인 균형 배치는 book을 오히려 뭉치게 했고,
  4-3 필드 이름 통일은 어느 도메인도 개선하지 못했다(9/17).
- **도메인 적대적 학습은 하지 않는다(10/25).** 인코더 뒤에 도메인 분류기를 붙이고 gradient
  reversal로 도메인 신호를 지우는 방법인데, 주로 지워지는 것이 위의 공통 성분이라 도메인별로
  검색하는 서비스에서는 결과가 거의 바뀌지 않는다. 도메인을 넘나드는 취향 연결이 나아질
  가능성은 있으나 그것이 문제라는 근거가 없고, 도메인 안 순위와 도메인을 지목하는 질문(direct)을
  해칠 위험이 있다. 백엔드가 세 도메인을 섞어 한 줄로 보여 주는 검색을 만들면 다시 본다.

## 5. 평가 도구의 문제 (남김)

모델 문제는 아니지만 4절이 확인되지 않는 원인이다.

1. **절대 등급은 본문 단어 겹침에 지배된다.** 질문과 본문 단어가 겹치지 않는 6월 256행에서
   사람은 41.0%에 o를 줬고 판정기는 2.7%에 줬다. 사람 라벨과의 완전일치는 42.5%다.
   그래서 9/9에 절대 등급을 버리고 쌍대로 판단하기로 했다.
2. **쌍대 판정기는 "단어는 겹치지만 오답"인 쌍을 못 가린다.** 사람이 두 번 같은 답을 낸
   역방향 29쌍에서 Qwen2.5-VL-7B 54.5%, Gemma 3 27B 36.0%(합격선 75%). 어휘 축을 겨냥한
   실험은 사람이 평가한다. API 판정기는 비용 문제로 쓰지 않는다.
3. **판정기가 순서에 흔들린다.** 순서를 바꿔 두 번 물어 같은 답이 나오는 비율이 약 69%라
   약 30%의 쌍이 판정에서 빠진다.
4. **평가 질문이 언어별 40개뿐이다.** 스타일별로는 10개라 작은 차이를 못 잡는다.
5. **원본 설명이 없는 아이템은 판정기가 볼 것이 없다.** 판정기는 합성 설명이 아니라 데이터
   원본 필드(영화 overview, 음악 description/가사, 책 blurb)만 본다 — 합성 설명을 보여 주면 그
   문체로 학습한 실행이 유리해지기 때문이다(의도된 설계). 원본 텍스트가 없는 아이템은 music
   3,657곡, movie 577편이고, 제목을 가리면 `Artist: …` 같은 한 줄만 남는다(평가 결과에 나온
   것은 240건, 판정 행의 3.2%). **모델 쪽은 문제없다** — 이 아이템들도 전부 합성 설명을 갖고
   있어 학습·검색에는 그것이 쓰인다. 사람 라벨 페이지는 제목과 커버를 함께 보여 주므로 사람
   평가에는 영향이 없다. 판정기 쪽 해법은 외부에서 원본 설명을 더 모으는 것뿐인데, 원래 텍스트가
   없던 덜 알려진 작품들이라 기대가 작다. 리포트에서 결손 행을 분리해 보는 지금 방식을 유지한다.
